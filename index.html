Core Features

Engineered with modularity, performance, and developer ergonomics at its core.

Modern Renderer Pipeline

Abstraction layer for modern graphics APIs. Supports Vulkan and OpenGL backend pipelines with customizable shader modules.

Entity-Component System

High-performance data-oriented ECS architecture designed for ultra-fast component iterations and cache efficiency.

Multi-Threaded Job System

Scalable job scheduler optimizing CPU core usage across physics, rendering submission, and async resource loading.

Scripting & Extensibility

Embedded Lua / C# binding hooks allowing fast gameplay prototyping without recompiling core engine binaries.

Asset Management System

Hot-reloading asset pipeline for meshes, textures, materials, and audio files with optimized serialization.

Spatialized Audio Core

3D positional audio system integrated with realistic attenuation, reverb spaces, and dynamic sound triggers.

Engine Architecture

Modular layer distribution built for clean dependency management.

Core Engine Subsystem

Memory management, custom allocators, math library, logger, and windowing system.

Render Hardware Interface (RHI)

Cross-platform abstraction layer interfacing directly with GPU drivers.

Scene & ECS Manager

Entity registration, component pools, transform hierarchies, and system execution order.

Getting Started

Clone, build, and start prototyping with Mio-Engine in minutes.

1

Clone Repository

Retrieve the latest source code along with recursive submodules.

git clone --recursive https://github.com/Mio-129/Mio-Engine.git
2

Generate Project with CMake

Build native visual studio solution or makefiles using CMake.

cmake -B build -S . -DCMAKE_BUILD_TYPE=Release
3

Compile & Run Examples

Build target binaries and run the sample sandbox application.

cmake --build build --config Release
SandboxApp.cpp 
#include <Mio/Engine.hpp>

class SandboxApp : public Mio::Application {
public:
    SandboxApp() {
        // Spawn entity in scene
        auto entity = GetScene()->CreateEntity("Player");
        entity.AddComponent<Mio::MeshComponent>("models/cube.obj");
        entity.AddComponent<Mio::TransformComponent>();
    }

    void OnUpdate(float deltaTime) override {
        MIO_LOG_INFO("Delta Time: {0}s", deltaTime);
    }
};

Mio::Application* Mio::CreateApplication() {
    return new SandboxApp();
}
